# FILA CERO

## Descripción
Gestión de atención estudiantil mediante colas en python. Este proyecto integra todo lo visto en el semestre tal como:
* POO
* Manejo de archivos
* Estructuras de datos, en este caso una cola (FIFO) 

## Tecnologías
- Python
- Librerias: tkinter, csv, dataclass, Optional, datetime, abstractmethod 

## Para correr el proecto 
"""bash
py main.py
"""
